# ☕ ระบบ POS ร้านกาแฟ (Coffee Shop POS System)

**Group15 Express Coffee — Smart POS Coffee Terminal**
รายวิชา CP352301 Script Programming · Final Project

## รายละเอียดโครงงาน

ระบบ POS (Point of Sale) สำหรับร้านกาแฟ พัฒนาด้วยภาษา Python เพื่อช่วยจัดการการขายหน้าร้าน
ตั้งแต่การรับออเดอร์ คำนวณราคา รับชำระเงิน ออกใบเสร็จ และสรุปยอดขายประจำวัน

- **Sprint 1:** พัฒนาเป็นโปรแกรมไฟล์เดียวบน Google Colab (แบ่งการทำงานเป็นฟังก์ชัน)
- **Sprint 2–3:** Refactor เป็นสถาปัตยกรรม 3 เลเยอร์ (Presentation / Business Logic / Data Access)
  รันบน Terminal พร้อมเก็บข้อมูลถาวรเป็นไฟล์ JSON, เพิ่มการค้นหา/กรอง/เรียงลำดับ และชุดทดสอบอัตโนมัติ

- เพื่อพัฒนาระบบขายหน้าร้านสำหรับร้านกาแฟ

## ความสามารถของระบบ

**จาก Sprint 1**
- แสดงเมนูเครื่องดื่ม
- เลือกขนาดแก้ว (S, M, L), ประเภทนม, ระดับความหวาน
- สั่งซื้อได้หลายรายการ
- ระบบสมาชิกและส่วนลด 10%
- คำนวณราคารวมอัตโนมัติ, รับชำระเงินสด, คำนวณเงินทอน
- พิมพ์ใบเสร็จ
- สรุปยอดขายประจำวัน

**เพิ่มใน Sprint 2–3**
- บันทึกข้อมูลถาวรลงไฟล์ JSON (เมนู, สมาชิก, ออเดอร์) ปิดโปรแกรมแล้วข้อมูลไม่หาย
- จัดการเมนูและสมาชิก (เพิ่ม / แก้ไข / ลบ / ดู)
- ค้นหาเมนูตามชื่อ, กรองตามช่วงราคา, เรียงตามชื่อหรือราคา
- ประวัติการขาย กรองตามวันที่ / ช่วงยอด / สมาชิก และเรียงตามเวลาหรือยอดรวม
- สรุปยอดขายรายวัน (เลือกวันได้) พร้อมเมนูขายดีและยอดส่วนลด
- กู้ไฟล์ข้อมูลอัตโนมัติเมื่อไฟล์หายหรือเสีย และจัดการข้อผิดพลาดจากการกรอกข้อมูล
- พิมพ์ `cancel` ที่ prompt ใดก็ได้เพื่อยกเลิกรายการปัจจุบัน

## วิธีใช้งาน

ต้องใช้ Python 3.9 ขึ้นไป (ทดสอบบน 3.12) ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```bash
git clone https://github.com/rapee29/final-project.git
cd final-project
python3 main.py                              # รันโปรแกรม
python3 -m unittest discover -s . -v         # รันชุดทดสอบ (56 tests)
```

1. เลือกเมนูที่ต้องการจากหน้าหลัก (`1` สั่งซื้อ, `2` สรุปยอด, `3` จัดการเมนู, `4` จัดการสมาชิก, `5` ประวัติการขาย, `0` ออก)
2. ทำรายการสั่งซื้อ เลือกขนาด นม ความหวาน และจำนวน
3. ระบุสมาชิก (ถ้ามี) รับชำระเงินและรับใบเสร็จ
4. ดูสรุปยอดขายประจำวันได้จากเมนู `2`

สมาชิกตัวอย่างสำหรับทดสอบ: `0812345678` (Somchai), `0898765432` (Somsri)
